# OTPサーバー仕様

本体（DJ-X100）が発行した OTP を受け取り、本体へ送り返す認証トークンを返す。

トークンの算出処理は x100cmd のコード内に含めないため、外部サーバーから取得する方式とする。そのため、OTP を外部へ送信する際はデフォルトで利用者の同意を必要とする（`--agree` で省略可能）。

本書はクライアントからの呼び出し仕様のみを定める。トークンの算出方法および OTP の検証方法は本仕様の対象外とし、公開しない。

## `GET /v1/otp/{otp}`

### 入力

| 項目 | 内容 |
| --- | --- |
| メソッド | `GET` |
| パスパラメータ `otp` | 本体が `AL~DJX100` に返した文字列 |
| リクエストボディ | なし |

#### リクエストのフォーマット（`otp`）

| 項目 | 内容 |
| --- | --- |
| 文字種 | 16進数（`0-9A-F`、大文字） |
| 長さ | 16文字（8バイト） |
| 例 | `5EA3327834745C10` |

`AL~DJX100` を送信するたびに異なる値が発行される。

```text
GET /v1/otp/5EA3327834745C10
```

### 出力

| ステータス | Content-Type | ボディ | 意味 |
| --- | --- | --- | --- |
| `200` | `text/plain;charset=UTF-8` | トークン（16文字の16進数） | 成功 |
| `400` | `text/plain;charset=UTF-8` | `NG` | OTP が不正 |
| `404` | `text/plain;charset=UTF-8` | `404 Not Found` | パス・メソッド不一致 |

#### レスポンスのフォーマット（トークン）

| 項目 | 内容 |
| --- | --- |
| 文字種 | 16進数 |
| 長さ | 16文字（8バイト）。クライアントは先頭32バイトまで読み、先頭16文字を使用する |

レスポンス例（成功）

```text
HTTP/2 200
content-type: text/plain;charset=UTF-8

<16文字の16進数トークン>
```

レスポンス例（OTP が不正）

```text
HTTP/2 400
content-type: text/plain;charset=UTF-8

NG
```

返されたトークンは `AL~DJX100<token>` として本体へ送信する。
